# 恐龙大冒险

一个根据小朋友手绘地图制作的卡通网页闯关游戏。

## 怎么玩

- 点击或轻触想去的位置
- 小恐龙会向目标移动，并在落地时自动起跳
- 也支持键盘方向键和空格
- 穿过弹跳圆环，避开尖刺、刺齿轮和恐龙嘴
- 找到钥匙，识破假箭头，抵达终点

## AI 小恐龙教练

教练会根据当前位置、钥匙状态和失败次数给提示。当前原型完全在浏览器本地运行，不调用外部 AI 服务，也不收集数据。

## 本地运行

直接打开 `index.html`，或使用本地服务器：

```bash
python3 -m http.server 4173
```

访问 <http://localhost:4173>。

## 技术

原生 HTML、CSS 和 Canvas JavaScript。无依赖、无构建步骤。
